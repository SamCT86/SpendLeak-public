# SpendLeak — Public Status

## Product

**Live:** https://spendleak.co.uk

SpendLeak currently offers a focused one-off Paid Traffic Integrity Assurance audit for performance teams. The live site is the authority for current price, ordering availability and customer-facing terms.

Current public product scope:

- one brand/domain
- up to 50 paid destinations
- reviewed destination evidence and prioritised actions
- client-forwardable frozen report
- one eligible follow-up comparison after remediation
- no ad-account write access

## Engineering

The production application is actively maintained in a private source repository. This public repository contains intentionally sanitised product/architecture material and does not mirror private source history.

Public engineering posture:

- production web application deployed on managed infrastructure
- server-side checkout/payment flow
- PostgreSQL-backed state model
- bounded destination evidence collection
- reviewed/frozen report pipeline
- private delivery and follow-up workflow
- CI/build and post-deployment verification gates

## Proof boundary

This repository does **not** claim public customer counts, revenue, case-study results or third-party endorsements that have not been independently supportable.

Screenshots and sample artifacts should be treated according to the labels shown on the live product. The public sample report is a demonstration, not customer proof.
